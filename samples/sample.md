# MdReader

一个轻量的 Windows Markdown 编辑器。把文件拖进窗口即可打开。点进预览里的段落，就能直接编辑 Markdown。也可以按 Ctrl+E 切换源码模式。

## 行内样式

- **粗体**、*斜体*、~~删除线~~、行内代码
- [网页链接](https://example.com)和[本文的使用提示](#使用提示)
- [同目录的 Markdown 文件](test.md)

### 列表

1. 打开 Markdown 文件
2. 点击要修改的段落

- 无序列表
  - 嵌套列表
- [x] 已完成事项
- [ ] 待办事项

> 这是引用。预览模式会保留换行和空行。

~~~cpp
// 代码块支持语法高亮
int main() {
    return 0;
}
~~~

| 操作 | 快捷键 |
| --- | --- |
| 保存 | Ctrl+S |
| 查找 | Ctrl+F |
| 打开大纲 | Ctrl+J |

## 使用提示

按 Ctrl+J 可在大纲中跳转。文件在外部保存后，打开的标签页会自动刷新。重新启动时会恢复上次查看的文件和位置。
